## What Was Built

### Task 1: UI Layer

**ElementEditorModal** (`app/src/components/editor/ElementEditorModal.tsx`)
- Full-form modal: label, widthM/heightM (cm), rotation (°) in core fields
- Footer: Delete (destructive), Cancel (ghost), Save (default) — testIDs `element-editor-delete/cancel/save`
- ESC listener with INPUT/TEXTAREA guard (Pattern S5, T-09.1-MODAL-ESC)
- D-21 discipline: label saved via top-level field, never written to provenance
- Layout: centered on Web (D-16), bottom-sheet on Mobile

**ElementEditorMoreFields** (`app/src/components/editor/ElementEditorMoreFields.tsx`)
- Collapsible section for note, plantedAt, accentColor (collapsed by default, D-11)
- Badge `(N)` shows count of filled extra fields when collapsed
- note: `<TextInput multiline maxLength={500}>` (T-09.1-DOS-NOTE)

**ZOrderButtons** (`app/src/components/editor/ZOrderButtons.tsx`)
- 4-button cluster: ChevronsUp/ChevronUp/ChevronDown/ChevronsDown (lucide-react-native)
- Pattern S2 Pitfall-5: `{ ...prev, zOrder: newZ }` preserves plantSlug/source/rotateDeg

**CrossPlatformColorPicker** (`app/src/components/editor/CrossPlatformColorPicker.tsx`)
- Web: native `<input type="color">`
- Mobile: lazy `require('reanimated-color-picker')` inside component body
- `HEX_RE = /^#[0-9a-fA-F]{6}$/` validation (T-09.1-XSS-COLOR, ASVS V5.1.3)

**CrossPlatformDatePicker** (`app/src/components/editor/CrossPlatformDatePicker.tsx`)
- Web: native `<input type="date">`
- Mobile: lazy `require('@react-native-community/datetimepicker')` — NO top-level import (Metro web bundle safety)

**i18n**: `packages/shared/src/i18n/de.json` — added `editor.elementEditor.*` block (22 keys, UTF-8 Umlaute)

### Task 2: Trigger Layer

**hitTest.ts** — GREEN fill of Wave-0 stub:
- `findElementAtPoint(elements, xM, yM)`: AABB, sortByZOrder ascending (last = topmost), ignores deletedAt
- Uses dedicated `widthM`/`heightM` columns (D-20, never provenance)

**WebPlanEditor.tsx** — dblclick trigger (D-01):
- `MOUSE_DRAG_THRESHOLD_PX = 5`: `pendingDragRef` captures mousedown, promotes to active drag only after 5px mousemove (T-09.1-DBLCLICK-RACE)
- `onDoubleClick` on element `<G>`: `e.stopPropagation(); setSelection(el.id); setEditingElementId(el.id)`

**EditorCanvas.tsx** — longPress trigger (D-02):
- `handleLongPressAt(xPx, yPx)`: converts screen→garden coords, calls `findElementAtPoint`, dispatches `setSelection` + `setEditingElementId`
- `Gesture.LongPress().minDuration(500).maxDistance(10).onStart(e => runOnJS(handleLongPressAt)(e.x, e.y))`

**plan/index.tsx** — modal mount in both shells:
- Mobile `PlanScreen` + Web `WebEditorShell`: reads `editingElementId` + `elements` from store
- Conditional `<ElementEditorModal>` with `onSave`→`updateElement+clearId`, `onCancel`→`clearId`, `onDelete`→`deleteElement+clearId`
