# Phase 09.1 Plan 04: Render Pipeline Summary

Render pipeline for both editor implementations (Skia + Web SVG) updated to use zOrder-sorted element arrays and per-element rotation transforms. Closes the perception gap between store state and pixel output — Z-Order buttons from Plan 02 and rotation handles from Plan 03 now have visible effect.

## What Was Built

**Task 1: EditorCanvas.tsx + WebPlanEditor.tsx render pipeline update**

- `EditorCanvas.tsx` (lines 21, 266–299, 301–330): `sortByZOrder` imported and applied to both `infrastructureEls` and `seasonalEls` before their `.map()` calls. Each element wrapped in a Skia `<Group>` with a 5-element transform array providing center-pivot rotation. NaN guard and accentColor hex validation applied.
- `WebPlanEditor.tsx` (lines 17, 347–430): `sortByZOrder` applied to `visibleElements`. Each `<G>` gets `transform={\`rotate(${rotateDeg}, ${cxPx}, ${cyPx})\`}`. Same NaN guard and accentColor hex validation. `finalFill` replaces `fill` for both `<Rect>` and `<SvgText>` to propagate the accentColor override.
- `setup.ts`: Added `maxDistance: () => g` to the gesture mock chain (pre-existing omission that was blocking the smoke test — Rule 1 auto-fix).

**Task 2: Rotation + zOrder render tests GREEN-filled**

- `EditorCanvas.rotation.test.tsx` (5 tests):
  1. "wraps element in Skia Group with rotation transform array [translate,rotate,translate] when provenance.rotateDeg=90" — asserts 5-element transform array with `rotate ≈ π/2`
  2. "sortByZOrder applied to infrastructure and seasonal layers before map renders" — spy confirms called ≥2x
  3. "uses widthM and heightM from dedicated columns, not provenance (D-20)" — Rect width=2.0 not 99
  4. "rotateDeg=0 results in identity rotation (rotate=0 in transform array)"
  5. "ignores non-finite rotateDeg (NaN) — falls back to rotate=0 (T-09.1-NAN-ROTATION)"

- `WebPlanEditor.rotation.test.tsx` (6 tests):
  1. "SVG <G> receives transform='rotate(deg, cxPx, cyPx)' attribute when provenance.rotateDeg set" — matches `/^rotate\(45,/`
  2. "renders without rotation when provenance.rotateDeg is missing"
  3. "ignores non-finite rotateDeg (NaN, Infinity) — falls back to 0 (T-09.1-NAN-ROTATION)"
  4. "renders elements sorted by zOrder ascending (higher zOrder renders last = on top)"
  5. "applies accentColor override when valid hex (T-09.1-XSS-ACCENT-COLOR)"
  6. "rejects invalid accentColor and falls back to default fill (T-09.1-XSS-ACCENT-COLOR)"
