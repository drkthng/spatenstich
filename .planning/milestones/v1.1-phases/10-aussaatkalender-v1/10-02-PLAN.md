<objective>
Build the data layer that feeds the calendar UI: a hook that joins the plant DB, the user's klimazone, and the plants actually placed in the active garden, plus a pure helper that answers "on which bed is this plant?".

Purpose: This plan turns the pure engine (plan 01) into app-bound data. `useKalenderData` resolves "diese Woche"-Aktionen and the "Nur meine Pflanzen" set, and exposes an `addPlantToPlan` action implementing CAL-05 (write a Pflanze element via the existing repo + outbox). `findBeeteForPlant` implements the "Auf welchem Beet?" lookup (CAL-04 placement context) by reusing the established PiP geometry. Critically, elements are loaded via `loadAcceptedElements(activeGardenId)` from `gardenPlanRepo` (the same path the Home screen uses) — NOT from `editorStore`, which is empty unless the editor is open.

Output: `useKalenderData.ts` hook (fills the Wave-0 stub), `kalenderBeete.ts` pure helper, and their tests.
</objective>
