<objective>
Schließe die Lücke "kein manueller Weg, einen Garten anzulegen". Seit dem M07-Pivot existiert kein Code mehr, der eine `garden_dimensions`-Zeile erzeugt — `saveDimensions()` in gardenPlanRepo.ts hat keinen einzigen UI-Caller. Folge: Ein Nutzer ohne Plan kann nur importieren; der Plan-Editor rendert ohne Dimensionen ein Dead-End (Web: nur Import-Review-CTA; Native: statischer Text).

Zwei Einstiegspunkte (Home-Empty-State + Editor-No-Dimensions-Fallback) führen dorthin.

Purpose: Manuelle Gartenplanung als Default-Weg (M07-Pivot) endlich von Null aus möglich machen.
Output: Neuer Screen + 2 Einstiegspunkte + i18n-Keys + 2 Test-Dateien. `saveDimensions`/`loadDimensions` bleiben unverändert.

## Vertrag von `saveDimensions` (gardenPlanRepo.ts — NICHT ändern)

```
saveDimensions(
  mode: AuthMode,                    // muss 'account' sein, sonst throw 'gardens are account-only'
  gardenId: string,                 // activeGardenId aus authStore (im Account-Modus gesetzt)
  dims: {
    shape: 'rectangle' | 'l_shape' | 'trapezoid' | 'freehand',
    widthM: number,
    heightM: number,
    extraDims: Record<string, unknown> | null,
  },
): Promise<GardenDimensionsRow>
```

- Wirft `Error('gardens are account-only')` wenn mode !== 'account'.
- Wirft `Error('not_authenticated')` wenn userId null.
- Upsert: existiert bereits eine Dimensions-Zeile, wird sie aktualisiert (id bleibt).

## authStore-Selektoren (authStore.ts)

- `useAuthStore((s) => s.mode)` → 'account' | 'local' | null
- `useAuthStore((s) => s.activeGardenId)` → string | null (im Account-Modus via ensureDefaultGardenForUser gesetzt)

## Router

- `useRouter()` → `{ push, replace, back }` (expo-router). Neue Route `/(app)/plan/new` wird durch die Datei `app/app/(app)/plan/new.tsx` automatisch registriert.
- Erfolg im Anlege-Screen → `router.replace('/(app)/plan')` (kein Back zum Form-Screen).

## UI-Bausteine (vorhanden, wie in plz.tsx)

- `Input` aus `@/src/components/ui/input` (props: value, onChangeText, keyboardType, inputMode, placeholder, testID, accessibilityLabelledBy)
- `Label` aus `@/src/components/ui/label` (prop: nativeID)
