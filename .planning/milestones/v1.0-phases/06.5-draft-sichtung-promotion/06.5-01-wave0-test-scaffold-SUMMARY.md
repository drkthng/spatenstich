## Decisions Made

- **Pure it.todo() over it.skip()** — `it.todo` requires no body and reads as intent ("test described, not yet implemented"). `it.skip` requires a body and reads as "test exists but disabled". Plan 02-04 conversion is a single-token replace (`it.todo('foo')` → `it('foo', () => { ... })`).
- **No imports of production targets** — The plan's `<key_links>` section names what imports Plans 02-04 will add. Wave 0 deliberately omits them so jest does not need the production files yet. This matches the plan's `<action>` guidance verbatim ("Do NOT import from draftPromotionRepo yet — those imports would fail TS compile").
- **process.env Supabase stubs at top of every node/hooks file** — even the i18n.review-keys.test.ts file gets them, although it does not touch Supabase. Matches the established `gardenPlanRepo.test.ts:5-6` convention so future test additions in this file pre-load the env.
- **Component tests use bare `describe()`** — no React imports, no `render()` calls, no mocks. Plan 03 adds all of these when wiring the impl. This keeps the scaffold under 12 lines per file and reviewable at a glance.
