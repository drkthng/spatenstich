## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking Issue] lucide-react-native ESM SyntaxError in component tests**
- **Found during:** Task 1 RED-run — first `pnpm exec jest --testPathPattern='preview-navigation'` failed with `SyntaxError: Unexpected token 'export'` from `lucide-react-native/dist/esm/lucide-react-native.js:8`. The components project's `transformIgnorePatterns: ['node_modules/(?!(@testing-library)/)']` excludes lucide from transformation; preview.tsx imports `InlineBanner` which imports lucide → unconditional load failure.
- **Fix:** Added a global jest mock at `components/__tests__/setup.ts` end:
  ```ts
  jest.mock('lucide-react-native', () => {
    const React = require('react');
    return new Proxy({}, { get: () => (_p: unknown) => React.createElement('Icon', null) });
  });
  ```
- **Why this scope:** preview.tsx must remain a true one-line edit per plan acceptance ("ALL other code in preview.tsx remains unchanged"). A global setup-level mock is the cleanest solution and benefits every future component test.
- **Files modified:** `app/src/components/__tests__/setup.ts`
- **Commit:** `97a6b15` (with the RED test).

**2. [Rule 1 - Bug] Infinite re-render in test due to unstable mock state**
- **Found during:** Task 1 RED-run after lucide mock was added — jest log showed `Warning: Maximum update depth exceeded` repeating 100+ times, plus the actual test failure.
- **Issue:** Mock returned `(sel) => sel({ payload: { … fresh object … }, reset: mockResetImport })` — every selector call (React re-renders trigger many) generated a new `payload` reference, which triggered `useEffect([payload])` in preview.tsx, which triggered another render, ad infinitum.
- **Fix:** Hoisted payload + store-state to module-scope constants. Selector now closes over a stable reference. `jest.clearAllMocks()` in `beforeEach` still clears call history because `mockResetImport` (a jest fn) is reused, not redeclared.
- **Files modified:** `app/src/components/__tests__/preview-navigation.test.tsx`
- **Commit:** `97a6b15` (same commit as the RED test).
