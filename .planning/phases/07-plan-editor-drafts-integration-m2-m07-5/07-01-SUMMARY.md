## Decisions Made

- **Editor jest project's testMatch overlaps with `stores` project** for `editorStore.*.test.ts`: both projects pick up the same files. Intentional — stores project tests in node env (no JSX); editor project ensures Skia/gesture mocks load when later component waves exercise editorStore via mounts. Quick command runs them once per project (157 todos in latest run reflects this dedup-by-project semantics).
- **editor setup.ts duplicates NativeWind + lucide mocks verbatim** from components setup.ts (rather than chaining setupFiles or sharing a partial) — keeps the editor project self-contained and avoids load-order pitfalls between projects. Cost: ~10 lines duplicated.
- **i18n placeholder uses `_placeholder` key rather than empty `{}`** — keeps JSON-Schema validators and TanStack i18n lookup helpers happy when they see the namespace exists. Plan 04 deletes `_placeholder` when filling concrete strings.
- **No production imports in any Wave-0 stub** — `it.todo()` does not require the target module to exist. This avoids TS compile failures until Plans 02-05 create the impls.
