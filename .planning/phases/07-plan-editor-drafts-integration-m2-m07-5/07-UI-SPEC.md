## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps inside toolbar buttons, badge inner padding |
| sm | 8px | Compact element spacing (toolbar button gap, palette card gap) |
| md | 16px | Default element spacing (screen edge padding, toolbar height inner pad, palette section pad) |
| lg | 24px | Section padding (bottom-sheet expanded body, modal body) |
| xl | 32px | Layout gaps (between toolbar and canvas in landscape, between palette tabs) |
| 2xl | 48px | Major section breaks (rare — bottom-sheet handle hit-zone height) |
| 3xl | 64px | Page-level spacing (top inset for floating toolbar when status bar visible) |

**Exceptions (touch-target floors):**
- Toolbar buttons: minimum touch target 44×44 (Apple HIG / WCAG 2.5.5). Visible icon 24×24 inside; padding 10px each side reaches 44.
- Palette cards: minimum 56×56 visible swatch + 12px label row = 80px total height. Long-press hit area expands to full card width.
- Bottom-sheet drag handle: 44px tall hit zone, 4×40 visible pill centered.
- Filter chips: 32px height with 12px horizontal padding, 8px gap.
- Skia canvas hit-test radius for plant selection: 24m-px (screen px equivalent at current zoom) — enforced in `editorStore` hit-test, not in CSS.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Caption | 12px | 400 | 16px (1.33) | `text-xs` | Toolbar icon labels (optional accessibilityLabel-only — labels hidden visually), filter-chip text, badge text |
| Body | 14px | 400 | 21px (1.5) | `text-sm` | Palette card label, draft-card body, toast/banner message, empty-state body |
| Label | 14px | 600 | 21px (1.5) | `text-sm font-semibold` | Draft-card title, palette section header, modal title |
| Heading | 18px | 600 | 24px (1.33) | `text-lg font-semibold` | Bottom-sheet expanded title ("Letzte Importe"), modal H1 |

**Rules:**
- Exactly 4 sizes, exactly 2 weights (400 regular + 600 semibold). No 500/700 anywhere.
- Body line height 1.5 (per Refactoring UI). Heading line height 1.33 (tighter for visual density).
- Skia text inside canvas (element labels): `labelFontSize = clamp(10, 14 / (widthM / 10), 14)` — same formula as `GardenPlanView.tsx:62`. Fill color `PLAN_COLORS.border` (#8B7355). Truncate at 10 chars with `\u2026`.
- **No serif fonts. No font weight 500 or 700.** German labels — UTF-8 Umlaute mandatory (ä, ö, ü, ß), never ASCII replacements.

### Color Contract Justification (60/30/10)

- **60% (stone-50 / stone-900):** Screen background, scroll surface, bottom-sheet body. ~60% of visible chrome pixels in a typical editor screen.
- **30% (stone-100 / stone-800):** Toolbar, palette tab bar, modal surface, draft-card background. ~30% of chrome.
- **10% accent (#4A7C59):** Primary CTA fills only (Save / Beet-abschließen / Promote / Auf-Beet-anwenden). Active filter chip. Save-success momentary icon. Counted in <10% of visible chrome at any moment.

**Canvas content is NOT counted in the 60/30/10 split** — the canvas is a domain visualization in sketch-warm tones (PLAN_COLORS), distinct from the surrounding app chrome by design.

### Destructive actions in this phase

| Action | Confirmation Approach |
|--------|----------------------|
| **Delete element** (toolbar Trash button while element selected) | Modal alert dialog with title + body + confirm/cancel (per Refactoring UI: destructive operations get a confirmation step). | **Cancel polygon-in-progress** | No modal — single-tap on toolbar "Zeichnen abbrechen" button discards in-progress points immediately (lossless: nothing was persisted yet). |
| **Dismiss draft from tray** (long-press → "Verwerfen") | Reuses existing `DraftReviewCard` dismiss button + Phase 6.5 P03 `dismissDraft` (sets status='dismissed', soft op via outbox). No new confirmation — Phase 6.5 already decided this was a soft op. |

### German-language rules

- All UI strings in German. UTF-8 Umlaute (ä, ö, ü, ß) — never ASCII `ae/oe/ue/ss`. Memory: `feedback_german_umlauts.md`.
- Sentence case for all labels except proper nouns ("Beete", "Pflanzen", "Infrastruktur" are nouns → capitalized).
- Imperative verbs for CTAs ("Speichern", not "Save it" or "Plan speichern").
- Ellipsis `…` (U+2026) for in-flight states ("Wird gespeichert …"), never `...`.

| Breakpoint | Behavior |
|------------|----------|
| < 360 dp width | Toolbar buttons: icon-only, no inline labels. Palette tabs: scroll horizontally if overflow. Drafts-tray chip: shortened to "Importe ({count})". |
| 360–768 dp (default mobile) | Toolbar 56px tall. Palette 88px tall (card 80 + 8 padding). Drafts-tray chip 36px floating bottom-left. |
| ≥ 768 dp (tablet portrait) | Palette becomes left-side rail (96 dp wide). Drafts-tray expands to right-side drawer. Toolbar remains top, 64 px tall. |

Web users land on read-only `GardenPlanView` from home; editor route shows "Editor zurzeit nur in der App verfügbar" message. (Not part of this UI-SPEC — flagged as deferred.) |

**Canvas viewport defaults (`--auto` decision for Claude's Discretion):**
- Initial scale: `min(viewportWidth / dimensions.widthM, viewportHeight / dimensions.heightM) * 0.9` (90% so a 5% padding ring is visible around the garden).
- Min zoom: 0.5 × initial scale (zoom-out to see context).
- Max zoom: 4 × initial scale (close enough to see individual plants at 200-element gardens).
- Pan limits: garden bounding-box ± 50% of viewport size (cannot pan beyond half a screen outside the garden).
- Reset button (right-aligned in toolbar, lucide `Maximize2`) → returns to initial scale + centers garden.
