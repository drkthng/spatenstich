## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Beliebige App auf dem Geraet -> /share-target | Jede installierte App darf an ein registriertes Teilen-Ziel senden; der Inhalt ist vollstaendig ungeprueft |
| Service Worker -> IndexedDB | Der Worker schreibt ohne App-Kontext in den lokalen Speicher |
| Cloudflare-Edge -> Browser-Cache | Die Cache-Header entscheiden, welche HTML- und Worker-Version ein Geraet sieht |
| Supabase-Redirect -> Web-App (detectSessionInUrl) | Der Client liest Auth-Fragmente aus der URL |
