## Fallback wenn Docker nicht geht

Wenn Docker partout nicht installiert werden kann (Win 11 Home ohne Hyper-V, etc.):

**Option A — Inline JSON in Edge Function:**
- Edit `supabase/functions/seed-plants/index.ts`
- Statt `await Deno.readTextFile('./plants.json')` → `import plantsJson from '../../packages/shared/src/data/plants.json' assert { type: 'json' }`
- Trade-off: violates Pitfall-6 (single-source-of-truth — bundle and edge function drift möglich)
- Workflow muss dann immer "edit JSON → smoke test → redeploy" sein, kein independent seed

**Option B — `--use-api` mit explicit bundle:**
- Versuch: `supabase functions deploy seed-plants --use-api --import-map deno.json --no-verify-jwt`
- Wenn das die static_files mitnimmt: Bingo, kein Docker nötig
- Unbestätigt — CLI 2.90.0 Docs zeigen das nicht explizit

**Option C — Manuelle SQL-Seed:**
- Lass Edge Function in Ruhe
- Generiere ein SQL-Script aus `packages/shared/src/data/plants.json` (`INSERT INTO plants ... ON CONFLICT (slug) DO UPDATE`)
- Führe das im Supabase SQL Editor aus
- D-17 Workflow-Doc anpassen
