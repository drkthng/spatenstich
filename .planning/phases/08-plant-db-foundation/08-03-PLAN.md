**Slug rules (schema-enforced):**
- Pattern: `^[a-z0-9][a-z0-9-]*[a-z0-9]$` (kebab-case ASCII; no umlauts, no underscores)
- Length: 2..64 chars
- Examples: `tomate` ✓, `busch-bohne` ✓, `johannisbeere-rot` ✓, `Möhre` ✗ (use `moehre` as slug; the `nameDe` field carries `Möhre` with the real Umlaut)

**Slug ↔ nameDe split (PLANT-DB-09 + CLAUDE.md feedback_german_umlauts):**
- **Slug**: ASCII-only kebab-case (for stable references; portable across systems that don't reliably handle UTF-8 in URLs/keys). `slug: "moehre"`.
- **nameDe**: full German with native UTF-8 Umlaute. `nameDe: "Möhre"`.
- **family**: full Latin botanical name. `family: "Apiaceae"`.
- **notesDe**: full German with native UTF-8 Umlaute. `notesDe: "Frostresistent; Säaussaat ab März."`.

<curation-notes>
- **DOY estimates** (Mitteldeutschland Klimazone 7a-8a; "Mitteldeutschland-Standardwerte" per CONTEXT D-05): use realistic ranges. Tomate sowIndoor 60-90 (March), plantOutdoor 130-150 (~mid-May after Eisheiligen). Buschbohne sowOutdoor 135-195 (mid-May to mid-July, succession plantings). Kartoffel plantOutdoor 100-130 (mid-April). Möhre sowOutdoor 80-180. Salat sowOutdoor 60-240. Erdbeere plant 210-250 (late summer; mehrjährig). Apfel + Obstbäume: harvestDoy only (no annual sow/plant).
- **JSON formatting:** Use 2-space indent for readability. Alphabetize plants by `slug` for diff-friendliness (per CONTEXT Claude's Discretion). Companions can stay in topical groups but slug-pair canonical (a<b lex compare).
- **iconEmoji:** Optional but nice. `🍅` Tomate, `🥕` Möhre, `🫛` Bohne, `🍓` Erdbeere, `🍎` Apfel, `🌿` Kräuter, `🌻` Sonnenblume, `🌼` Ringelblume, etc. Set to `null` if unsure.
- **File size:** Expected ~50-80 KB final. The Edge Function + Metro bundling both can handle this comfortably (Pitfall 8 accepted in RESEARCH).
- **License hygiene reminder:** EVERY plant.dataSource MUST be one of: `gardeneus | garden-planner | own-research | merged`. The validator's ajv enum (PLANT-DB-09 enforced in Wave 0+1) will REJECT the literal `"gartenplaner"`. If you find a fact via the Gartenplaner CSV, re-verify it from a primary source (Wurzelwerk, Kleingartenkompendium, OBI Garten, Permakultur-Plattform) — then tag as `"own-research"`.
- **Why use validator (not just the schema)?** The validator catches the cross-ref errors (unknown slug, self-companion, duplicate pair) that the schema alone cannot — see RESEARCH §Pattern 3. Smoke test PLANT-DB-01 calls `validatePlantBundle(bundle)` as the very first assertion.
- **DOY: only realistic combinations.** A perennial Obstbaum may have `sowOutdoorDoyStart: null` (we don't sow apple trees from seed at home; we plant grafted nursery stock). `plantDoyStart` can be set for the planting season. Mehrjährige Beeren handled similarly.
- **nitrogenFixing**: ONLY Fabaceae (busch-bohne, stangen-bohne, erbse, zucker-erbse, lupine if added). All others: false.
- **perennial**: TRUE for Obstbäume (apfel, birne, ...), Beeren (erdbeere, himbeere, ...), and woody Kräuter (rosmarin, salbei, thymian, lavendel — though herbs can be debated; conservative: rosmarin + lavendel + heidelbeere = perennial; salbei + thymian = perennial in mild winters; treat heidelbeere as perennial; basilikum NOT perennial).
