<objective>
Build the pure calendar engine and the German i18n string tree that the rest of Phase 10 consumes, and lay down the Wave-0 test scaffold that downstream plans (02, 03) fill.

Purpose: The engine is the deterministic core (DOY→ISO-KW conversion, klimazonen offset, "diese Woche" filter, single-season Fruchtfolge check). It lives in `packages/shared` as pure TypeScript so it is testable in the node jest project and reusable from both web and native. This plan delivers CAL-02 (klimazonen offset), CAL-03 (Vorkultur/Direktsaat/Auspflanzen/Ernte distinction in the window model), and CAL-06 (Fruchtfolge check function). It also creates the i18n keys and the stub test files for the hook and component built in later waves.

Output: `kalenderEngine.ts` (exported via shared index), `de.json` `kalender.*` keys, an i18n key test, an engine test, and two `it.todo` stub test files for Wave 2/3 consumers.
</objective>
