# Fonts

Fraunces and Newsreader, variable weight, Latin subset (covers German). Shipped with the app so
no request goes to a third-party server (DESIGN3-02). Both are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org).

- Fraunces — Copyright The Fraunces Project Authors (https://github.com/undercasetype/Fraunces)
- Newsreader — Copyright The Newsreader Project Authors (https://github.com/productiontype/Newsreader)

Files were taken from the Fontsource distribution of the Google Fonts releases.
